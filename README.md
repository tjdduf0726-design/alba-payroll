# 알바 월급 계산기 (PWA)

근무 기록만 넣으면 **기본급 · 야간수당 · 연장수당 · 주휴수당 · 4대보험/3.3% 공제**까지
한 번에 정산하는 알바 급여 계산기입니다. 설치형 웹앱(PWA)이라 휴대폰 홈 화면에 앱으로
추가할 수 있고, 한 번 열면 오프라인에서도 동작합니다.

- 🔒 모든 계산은 브라우저 안에서만 처리됩니다. 급여·계좌 정보는 어디로도 전송되지 않습니다.
- 📅 알바별 · 월별로 정산 기록을 저장하고 다시 열어볼 수 있습니다.
- ⏰ 출퇴근 시각(예 `20:00~02:00`)만 넣으면 근무시간·야간시간을 자동 계산합니다.

## 구성
- `index.html` — 앱 본체 (계산 로직 포함)
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA 설치·오프라인용

## GitHub Pages로 배포하기
1. 이 저장소의 **Settings → Pages** 로 이동
2. **Build and deployment → Source** 를 `Deploy from a branch` 로
3. **Branch** 를 `main` / `/ (root)` 로 선택하고 **Save**
4. 잠시 후 표시되는 `https://<아이디>.github.io/<저장소이름>/` 주소를 휴대폰에서 열고
   브라우저 메뉴의 **"홈 화면에 추가"** 로 앱 설치

> 공제 요율은 2025년 기준 근사치입니다. 실제 신고·이체 전 세무사 확인을 권장합니다.
